Co poprawia względem obecnego okna

  • Jedna główna akcja: niebieski „Commit do alpha”; reszta to przyciski drugiego planu.
  • Stan repo widać od razu: kolorowa kropka, licznik zmian, czerwony znacznik konfliktu, wyszarzone repo niedostępne.
  • Pasek narzędzi nazywa wybrane repo i gałąź z upstreamem; Pull jest tam, gdzie ma sens.
  • Podpowiedzi klawiszy pojawiają się przy zaznaczonym wierszu, więc spacja i dwuklik nie są ukryte.
