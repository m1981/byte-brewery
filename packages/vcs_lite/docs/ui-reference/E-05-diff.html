vcs-lite — diff lewo–prawo w przeglądarce (propozycja, Q-VCS-057)

Zastępuje Beyond Compare (DEC-VCS-102) dla plików tekstowych innych niż .md: ta sama strona co diff Markdown (pasek, kolory, motyw z menu Widok), w środku tabela obok siebie (DEC-VCS-103). Tylko do odczytu (DEC-VCS-104).
