P9 Pytanie o upstream

Natywne okno macOS (tkinter.messagebox.askyesno), zgodnie z DEC-VCS-047. Treść mówi wprost, że commit już jest zapisany. Napisy przycisków ustala system (Tak/Nie); własne napisy wymagałyby własnego okna.

vcs-lite — alpha
vl Gałąź feature nie ma upstreamu Commit został zapisany. Wypchnąć gałąź do origin i ustawić upstream?

P10 Odłączony HEAD

Chip pokazuje skrót commita zamiast gałęzi. Commit działa, Commit & Push i Pull są nieaktywne (UC-VCS-02, krok 2b). Przyczyna przy przycisku Commit & Push widoczna po najechaniu.

alpha⎇ odłączony HEAD · a1b2c3d
