HTML pokazuje układ i zachowanie; wygląd suwaka jest przybliżeniem. W aplikacji użyjemy standardowego ttk.Scrollbar w motywie macOS. Paski poziome nie są tu potrzebne: nazwy są skracane, a opis commita zawijany.
